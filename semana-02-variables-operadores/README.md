# Semana 02 - Calculadora de Edad

## Descripción
Programa de consola en Java que solicita el nombre completo del usuario, su año de nacimiento y el año actual para calcular su edad aproximada, su edad en meses y determinar si es mayor de edad mediante operadores de comparación.

## Datos Solicitados
* Nombre completo (`String`)
* Año de nacimiento (`int`)
* Año actual (`int`)

## Cálculos Realizados
* **Edad aproximada:** `anioActual - anioNacimiento`
* **Edad en meses:** `edadAproximada * 12`
* **Mayoría de edad:** `edadAproximada >= 18`

## Instrucciones para Ejecutar
1. Abrir el proyecto `semana-02-variables-operadores` en IntelliJ IDEA.
2. Navegar a `src/CalculadoraEdad.java`.
3. Hacer clic derecho sobre el archivo y seleccionar **Run 'CalculadoraEdad.main()'**.
4. Ingresar los datos solicitados en la consola.
