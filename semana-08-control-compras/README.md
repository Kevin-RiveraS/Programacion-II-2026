## Control de Compras del Hogar
Este proyecto es una aplicación desarrollada en Java para la gestión, registro y análisis de compras semanales dentro de un hogar. Su objetivo principal es aplicar conceptos avanzados de la Programación Orientada a Objetos (POO), estructuras de control y la selección eficiente de Colecciones en Java (ArrayList, HashSet y HashMap).

El sistema permite registrar un listado de productos, realizar validaciones lógicas de los datos ingresados, procesar los acumulados por categoría, determinar los productos con mayor y menor impacto económico, y permitir consultas inmediatas por categoría.
