## 📖 Descripción
Programa de consola en Java que simula el funcionamiento de un cajero automático para una sola cuenta bancaria.  
Incluye:
- Control de acceso por PIN
- Depósitos
- Retiros normales y con comisión
- Resumen de sesión
- Sobrecarga de métodos

## ▶️ Ejecución
1. Abrir el proyecto en IntelliJ IDEA.
2. Compilar y ejecutar la clase principal `CajeroAutomatico.java`.
3. Seguir las instrucciones en consola.
